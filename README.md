# 💫 About Me:
Hi, I'm Damilare (Excel). I build payment infrastructure on Stellar. Software engineer working in Rust/Soroban and TypeScript, based in Lagos.

**DukaPay:** an open-source agent-banking protocol that turns local shops into stablecoin cash-in and cash-out points. I wrote the first version of the agent vault contract: collateral-backed float limits and batched end-of-day settlement that has to net to zero or gets rejected. I maintain the repo, CI and security gates.

**TrustLink:** a decentralized B2B escrow and reputation protocol on Stellar Soroban. It replaces the "pay first" trust gap in cross-border service agreements with a milestone-based escrow vault, on-chain dispute resolution and a verifiable reputation system. Full monorepo: Soroban contracts, a Rust indexer with REST/WebSocket APIs, a Next.js dashboard and a TypeScript SDK.

**Open source:** 34 PRs merged into other projects in September 2026, covering Soroban contracts, backend APIs, frontend features and security fixes. Outside Stellar, I've started contributing to [Meshery](https://github.com/meshery/meshery) (CNCF).

**Before engineering** I was a designer. I designed Amana's UI in Figma and reviewed contributor PRs for its open-source team.

**What I work on**
- Smart contracts: escrow, milestone-based payments and on-chain reputation in Rust/Soroban
- DeFi on Stellar: lending, remittance, payments, prediction markets and savings circles
- Backend: real-time blockchain indexers in Rust (Axum, Tokio, SQLx) bridging on-chain data to PostgreSQL
- Frontend: Next.js dashboards and Freighter wallet integrations

**Interests:** applications that serve African markets, like remittances, escrow for agriculture, savings circles and low-cost payments.

I build with AI tools and I'm responsible for every change that ships under my name. I write about what I learn on [LinkedIn](https://www.linkedin.com/in/oluwadamilareoduyomi/).
