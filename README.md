# 💫 About Me:
ExcelDsigN-tech is a blockchain developer building on the Stellar network, with a focus on Soroban smart contracts (Rust) and full-stack TypeScript applications. Since creating the account in February 2026, they've maintained a consistent and high-velocity open-source contribution record — 16+ merged pull requests across Stellar ecosystem projects.<br><br>Core focus areas:<br>- Smart contract development — escrow, milestone-based payments, and on-chain reputation systems in Rust/Soroban<br>- Decentralized finance — lending, remittance, payments, prediction markets, and savings-circle protocols on Stellar<br>- Backend infrastructure — real-time blockchain indexers in Rust (Axum, Tokio, SQLx) bridging on-chain data to PostgreSQL<br>- Frontend engineering — Next.js dashboards and wallet integrations (Freighter)<br><br>Flagship project — TrustLink: A decentralized B2B escrow and reputation protocol built on Stellar Soroban. TrustLink replaces the "pay first" trust gap in cross-border service agreements with a milestone-based escrow vault, on-chain dispute resolution, and a verifiable reputation system. It's a full monorepo: Soroban contracts, a Rust indexer with REST/WebSocket APIs, a Next.js dashboard, and a TypeScript SDK.<br><br>Contributor activity: An active participant in the Stellar ecosystem's open-source contribution program, opening feature PRs across multiple projects — admin rotation for lending contracts, donor history for green-payments, and emergency-withdrawal fixes for community launchpads — while also closing security-hardening issues (dependency scanning, CSP, secrets rotation, CI hardening).<br><br>Interests: Applications that serve African markets — remittances, escrow for agriculture, savings circles, and low-cost payments.
